# PLAYBALL 모델 카드

## 현재 버전: `stats-v7-game-context`

v7은 더블헤더의 선발 유형·배당 연결과 기록 검증을 유지하면서 승리 팀을 반올림 전 확률로 선택한다. 이전 버전의 성능과 보정기는 v7에 섞어 사용하지 않는다. 기존 예측은 과거 조회와 전체 모델 성능 조회에서 계속 확인할 수 있다.

현재 승률은 학습 모델이 아니라 설명 가능한 통계 추정식이다. 다음 값을 리그 평균과 표준편차로 정규화한 뒤 로짓 공간에서 결합한다.

- 팀 득점/경기: 45%
- 팀 평균자책점: 35%
- 팀 출루율: 20%
- 팀 종합 지표 차이: 최종 로짓 계수 0.50
- 예고 선발 ERA·WHIP 지표 차이: 최종 로짓 계수 0.20
- 직전 3일 불펜 투구 수와 이틀 연속 등판 인원: 최종 로짓 계수 0.10
- 홈 기본 보정: 로짓 0.13
- 1군 엔트리에서 빠진 상위 6명 타자: 시즌 타석 비중에 따라 팀당 로짓 최대 0.09 감점
- 구장 득점 사전계수·기온 계수: 팀 종합 지표 차이의 크기를 보수적으로 조정

설명형 추정치의 과신을 막기 위해 보정 전 승률은 28~72%로 제한한다. KBO 공식 등록 명단은 부상 진단이 아니므로 화면에서도 `엔트리 이탈`로만 표현한다.

## 역배 가치 판정

- moneyline 배당의 북메이커별 암시확률에서 마진을 제거하고 중앙값을 시장확률로 사용한다.
- 시장확률이 낮은 팀을 역배로 정의한다.
- 기대수익은 `모델 승률 × 해당 팀의 최고 decimal 배당 - 1`로 계산한다.
- 역배 EV 8% 이상, 시장 대비 엣지 5%p 이상, 정배 대비 EV 우위 10%p 이상을 모두 충족할 때만 추천한다.
- 최소 2개 북메이커를 비교하고, 양 팀 최고 배당이 60분 이내에 갱신됐으며 경기 시작 10분 전일 때만 추천한다.
- 실제 배당이 없거나 API가 연결되지 않으면 대체 추정치로 역배를 생성하지 않는다.
- 제공사 이벤트 ID를 보존하고 같은 팀·시작 시각의 KBO 경기 ID에 일대일 연결한다. 시작 시각 차이가 60분을 넘거나 매칭이 모호한 경우 배당을 연결하지 않는다.

타자의 1안타 이상 확률은 시즌 타율을 리그 평균 60타수 사전분포로 보정한다. 이후 상대 예고 선발의 좌투·우투·언더 유형별 타율을 35타수 사전분포로 다시 보정하고, 선발 ERA와 타순별 예상 타수를 반영한다.

상대 선발 유형은 경기 ID와 홈·원정 구분으로 조회한다. 더블헤더에서 필요한 유형별 기록을 모두 수집하고 선수의 순위에도 경기 ID와 시각을 보존한다. 투구 유형을 확인하지 못하면 우투로 가정하지 않고 시즌 타격 기록만 사용한다.

공식 기록은 컬럼 이름으로 해석하고 필수 컬럼·팀 필터·숫자 범위·타수/안타 관계를 검증한다. 구조가 잘못된 필수 자료는 오류로 처리한다. 정상 구조에서 선수 표본·엔트리·날씨 등이 부족한 경우 보완에 사용한 자료와 누락 상태를 화면에 표시한다.

## 시간 순서와 데이터 누수 방지

- 같은 경기·모델·라인업 상태는 가장 최근 경기 전 예측으로 갱신한다. 늦게 도착한 이전 시각의 요청은 최신 기록을 덮어쓰지 않는다.
- 각 경기의 라인업 확정 여부와 진행 상태를 개별 판정해, 저장 가능한 다른 경기가 함께 누락되지 않게 한다.
- 경기 당일 해당 경기 시작 전에 생성된 예측만 성능 평가 대상으로 저장한다.
- 캐시 응답도 현재 시각으로 배당 신선도와 추천 마감을 재판정한다. 경기 시작 이후에는 캐시된 경기 전 분석을 평가용 기록으로 저장하지 않는다.
- 확정 라인업 예측이 있으면 경기 평가는 확정 예측을 우선한다. 역배 ROI와 임계값 검증도 같은 경기 예측의 모델·라인업 상태·시각에 연결된 배당만 사용한다. 최종 스냅샷이 추천하지 않거나 배당이 없으면 이전 추천을 되살리지 않는다.
- 각 수집 시점의 예측은 별도 변경 이력에 보존한다. ROI는 실제 체결 기록이 아닌 최종 스냅샷을 따라 경기당 1단위를 선택한 가상 성과다.
- 승리 팀은 반올림 전 승률로 결정하며 표시 확률은 소수점 한 자리까지 사용한다. 50% 근처에서 반올림 때문에 더 낮은 승률의 홈팀이 선택되지 않게 한다.
- 성능 지표와 역배 ROI는 기본적으로 현재 활성 모델 버전만 집계한다.
- 무승부는 이진 승패 적중률, Brier Score와 단위 베팅 ROI 정산에서 제외한다.
- 과거 경기 결과로 현재 예측을 다시 생성해 과거 성능처럼 표시하지 않는다.
- 과거 날짜의 기본 조회는 경기별로 저장된 당시 예측이다. 상세 자료가 없는 구버전 기록은 승률만 표시한다. 사용자가 선택한 현재 기록 재분석은 별도로 표시하고 성능 평가와 배당 추천에서 제외한다.
- 학습 모델은 충분한 시점별 스냅샷이 축적된 이후 날짜 기준 train/validation/test 분할로만 도입한다.
- Platt 보정기는 같은 `stats-v7-game-context` 예측 최소 100경기에서 날짜 앞 60%를 학습, 다음 20%를 검증, 마지막 20%를 테스트에 사용한다. 같은 날짜의 모든 경기는 같은 구간에 배치하며 검증·테스트 각각 최소 20경기가 필요하다.
- 검증 Brier Score가 개선될 때만 활성화한다. 별도 테스트 구간은 학습과 활성화 판단에 사용하지 않고 최종 성능을 기록한다. 테스트 결과를 보고 설정을 반복 조정하면 독립 검증이 아니므로 이후 새로운 기간으로 평가해야 한다.
- 검증 Brier Score는 실제 서비스와 같은 확률 보정 함수와 20~80% 제한을 적용해 계산한다.

## 현재 한계

- 구장 득점 계수는 적은 범위의 사전값이며 시점별 결과가 쌓이면 재학습해야 한다.
- 날씨는 기온으로 득점 환경을 조정하고, 강수 가능성은 신뢰도 표시에만 사용한다. 바람 방향과 구장 방위는 아직 미반영이다.
- 배당은 시시각각 변하며 역배 EV는 조회 시점의 가격에만 유효하다.
