# PLAYBALL 모델 카드

## 현재 버전: `stats-v2-starter`

현재 승률은 학습 모델이 아니라 설명 가능한 통계 추정식이다. 다음 값을 리그 평균과 표준편차로 정규화한 뒤 로짓 공간에서 결합한다.

- 팀 득점/경기: 45%
- 팀 평균자책점: 35%
- 팀 출루율: 20%
- 팀 종합 지표 차이: 최종 로짓 계수 0.50
- 예고 선발 ERA·WHIP 지표 차이: 최종 로짓 계수 0.20
- 홈 기본 보정: 로짓 0.13

아직 부상과 불펜 소모를 반영하지 않으므로 승률은 28~72%로 제한한다.

타자의 1안타 이상 확률은 시즌 타율을 리그 평균 60타수 사전분포로 보정하고, 상대 예고 선발 ERA와 타순별 예상 타수를 반영한다.

## 시간 순서와 데이터 누수 방지

- 같은 날짜·모델·라인업 상태의 최초 예측을 보존하고 이후 요청으로 덮어쓰지 않는다.
- 확정 라인업 예측이 있으면 경기 평가는 확정 예측을 우선한다.
- 과거 경기 결과로 현재 예측을 다시 생성해 과거 성능처럼 표시하지 않는다.
- 학습 모델은 충분한 시점별 스냅샷이 축적된 이후 날짜 기준 train/validation/test 분할로만 도입한다.

## 현재 제외된 변수

- 최근 3일 불펜 투구 수와 연투 여부
- 타자·투수 좌우 유형별 상대 기록
- 엔트리 말소와 부상 정보
- 구장별 득점 계수와 날씨

이 변수들은 공식 원천 데이터의 안정적인 시점별 수집이 확보된 뒤 추가한다.
